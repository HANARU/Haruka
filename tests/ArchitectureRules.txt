# 모듈 의존 규칙(엔진 구조 안정화 S1, 2026-11-18). 설명 · 이유는 Docs/Engine_Structure_Design.md 의 정본입니다.
# HarukaArchTest(ctest architecture_deps)가 src 아래 모든 `#include "..."` 를 이 표와 맞춰 봅니다.
#
#   module <이름>: <include 해도 되는 다른 모듈들>     같은 모듈 안은 늘 됩니다. 나열하지 않은 방향은 안 됩니다.
#   allow <포함하는 파일> -> <포함되는 파일>            아직 고치지 않은 위반(src 기준 경로). 고치면 지웁니다.
#
# 새 폴더(모듈)를 만들면 여기에 규칙부터 적으십시오. 표에는 순환이 없어야 합니다(시험이 확인).
